### 업로드 시 주의

- 이번 작업은 **Markdown 작성과 로컬 회원 기준표의 ID 추가까지** 수행했다. 운영 API 업로드, S3 동기화, 프런트엔드 배포, 8월 원본 JSON 파일 생성은 수행하지 않았다.
- 운영 서버가 신규 ID를 허용하려면 서버가 참조하는 회원 기준표에도 S037·S038이 반영되어야 한다. 현재 프런트엔드는 회원 ID 목록을 빌드 시 읽으므로 웹도 갱신해야 한다.
- 기존 26명은 `previousFans`를 명시했으므로 서버의 과거 자료 조회나 자동 보정에 의존하지 않는다. 남극곰 7월 자료가 없는 여름·낸데는 현재 구현상 0으로 보정되어 “신규”로 표시될 수 있지만, 이는 실제 전월 팬 수가 0이었다는 증거가 아니다.
- 현재 앱은 이전 값을 0으로 보정한 회원의 누적 팬 수도 전체 증가량 카드에 포함한다. 제공 자료와 동일하게 보정하면 **6,045,032,743명**을 표시할 수 있으나, 본 문서의 확인 가능한 월간 증가량 **3,152,301,802명**과는 집계 기준이 다르다.
- 기존 26명의 이전값을 명시해 순수 로컬 저장 경로의 정적 이력 보정 제약도 피했다. 전월값 미확인 2명 때문에 생기는 집계 차이는 남으므로 앱의 증가량을 이 원장과 대조해야 한다.
- 인원 29명 중 확인되지 않은 1명의 자료가 추가되면 원장과 JSON을 보완해야 한다. 누락 회원을 임의 ID나 0 팬 수로 채우지 않는다.

## 6. 추출·정규화 기준

- 회원 이름은 사용자 확정 명단과 이미지로 확인했다. **츄휴**는 사용자 정정에 따라 S030을 유지했다.
- 이름이 같다는 이유로 남극곰·북극곰의 ID를 섞지 않았다.
- 신규 ID는 이번 요청에 따라 발급했다. 일반 참고 프롬프트의 “미확정 ID는 제외” 규칙과 달리, 여름·낸데는 사용자에게 신규 ID 배정 권한을 받은 항목이다.
- `곰> 4Mix`의 기호·대소문자, `토카이 테이오`의 공백, `BIB`의 대문자를 기준표대로 유지했다.
- 팬 수의 쉼표와 “명” 단위는 JSON에서 제거하고 정수로 입력했다.
- 모든 회원은 고유한 S 계열 ID를 사용하며 28개 레코드에 중복 ID가 없다.
- 최종 로그인 시각, 담당 캐릭터, 칭호는 팬 수 데이터에 포함하지 않았다.
- 이미지 05의 “현재 집계 중”, “지난달 16위”는 화면에 표시된 문구로만 확인했다. 별도 결과 확인 없이 8월 최종 확정 순위로 단정하지 않았다.
- 첨부 파일 이름은 2026-09-01을 포함한다. 결산 귀속 기간 `2026-08`은 사용자의 요청을 따랐으며, 게임 내 월말 마감 시각과 촬영 시각의 일치 여부는 검증하지 않았다.

## 8. 후속 확인 사항

1. **이미지에서 확인되지 않은 1명의 이름과 팬 수:** 현재 29명 표기 대비 28명만 포함되어 있다.
2. **여름·낸데의 남극곰 전월 비교 기준:** 정확한 월간 증가량이 필요하면 7월 말 누적값 등 확인 가능한 기준값을 추가해야 한다. 북극곰 기록이나 이름이 다른 사람의 기록으로 임의 보정하지 않는다.
3. **최종 순위:** 이미지의 집계 중 상태와 별개로 확정 결산 순위가 필요하면 추가 근거를 확인한다.
